**End-of-day wrap.** Run when the owner is done for the day:

1. **Update today's daily log** (`01_Daily_Log/YYYY-MM-DD.md`) with the day's actual work — decisions, results, what was shipped.
2. **Write the carry-over list** for tomorrow.
3. **Check the continuity note** (State of the Union / handover note) is current.
4. **Ready-check:** confirm the vault is saved, backed up (if a backup step exists), and tomorrow's session can pick up cleanly.

> Keep it calm and complete. The daily log is the single clean memory of the day. In this starter vault there may be no external-drive backup script yet — the owner can add one; see the "Keeping the System Healthy" note.
