**LOAD THE FRESH THREAD.** This is the universal loader. When the vault owner starts a fresh thread (or says "load me in"), load the whole system so they never have to re-explain anything. Then finish by offering the what-next engine.

## What to load
1. **Read the Start Here notes** (`99_Start Here/`) so you absorb the system's philosophy, workflows and permissions model.
2. **Read today's daily log** in `01_Daily_Log/` (create `YYYY-MM-DD.md` if it's the first session of the day). That is the anchor timeline.
3. **Read the State of the Union / continuity note** if one exists (a handover note at the top of the vault, often in `07_Metadata/`) so you pick up exactly where the last session left off.
4. **Check the inbox** (`00_Inbox/`) — titles only; suggest filing.
5. **Import any voice notes** from the dictation capture folder if the ritual is set up (see the Voice Capture note).
6. **Finish by offering the what-next engine** — tell the owner they can say **"what's next?"** any time and you'll return ONE next action.

> If the owner has their own folders/scripts set up (this is a starter vault — they will personalise it), the daily.md note in THEIR vault may have richer steps. Adapt to what's actually present.
